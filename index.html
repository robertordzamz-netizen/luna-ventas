Sobre la aplicación

Luna Ventas permite gestionar prospectos, solicitudes de servicios técnicos, cotizaciones, seguimientos, pagos y campañas desde un panel local. La aplicación se utiliza exclusivamente para la operación interna de SYSTEMEETS; no se vende acceso a terceros. La integración oficial con TikTok todavía está por implementar.
